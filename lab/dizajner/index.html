How to use this

  
For games, one line runs along the top: ① Start → ② Machine → ③ Run ↺.

  
    
    
  1. ① Start — three doors: your words (the assistant turns them into bricks — patterns from the catalog, each with a reason), a game you love (how the catalog sees it), or an empty board.
    2. 
    
  2. ② Machine — your bricks on a board: up — what the player feels, middle — what happens in play, down — the rules; columns — parts of the game (Fullerton). The catalog’s wires run bottom-up — hover one for why. On top is the roof: MDA’s eight kinds of fun; a feeling wires up to the kind it is a form of; 📌 pin what you aim for. Click a brick: why it is here, its wires, ⇄ others like it, ✕ take it out. A red socket — or a pinned kind with no wire — asks a question: choose one of three. Scroll over the board to zoom.
    3. 
    
  3. ⚡ Run the machine — the builder makes a grey prototype from it.
    4. 
    
  4. ③ Run — play, ● Start test, talk to the game’s design assistant; under the game — what happened to each brick: ● works · ⚠ a label · ○ not built.
    5. 
  

  
Worlds keep their own two screens.
