Как играется (`v20/index.html`, `SAMPLE_SETS`): каждая нота — ближайшая запись, подстроенная скоростью (не дальше полутора полутонов);
рояль звучит своим естественным спадом, глушится педалью, тихое касание темнее; виолончель — каждый штрих своей записью, долгая нота
держится петлёй середины записи (1,0–2,9 с); контрабас — щипок, глушится по длине. Пока записи не загружены или их нет (страница из файла) —
играет синтез (ручка «sound» 0). Файлы не трогать руками: имена — те, что ждёт страница.
